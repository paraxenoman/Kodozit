## Kodozit.Seos
**Kodozit.Seos** — задуман как AWK расширенный в сторону Spoofax с отдельных файлов на деревья папок и файлов + более параметризованный некоторой грамматикой (AWK тоже параметризован, но очень ограниченно).  

**Kodozit.Seos** — это статически типизированный язык для генерации иерархии структурированных текстовых файлов.
